# Протокол «Конспект» — формат тесту (довідково)

З 2.8 карток після кожного заняття немає. Цей формат — лише для тесту перед колоквіумом, коли студент сам попросить.

## Формат `quiz.json` v2
`{"version":2,"cards":[ … ]}` — кожна картка має `type` і `q`; спільні поля (необов'язкові, але бажані):
`hint` (масив 1–2 поступових підказок), `explain` (чому так, 1–2 речення), `source` (`{"t":"00:12:34"}` — мітка часу з
`transcript.txt`, або `{"section":"3. Planowanie"}` — розділ конспекту), `tags`, `important` (true — прозвучало «na kolokwium/egzamin»).
- `mcq`: `"options":["A","B","C","D"]`, `"correct":0` (індекс), `"traps":{"1":"чому B — пастка"}` (для правдоподібних хибних варіантів);
- `cloze`: `q` з `___` на місці слова, `"answer":"слово"`, `"accept":["синонім"]` (перевірка без регістру/діакритики, з допуском описок);
- `tf`: твердження в `q`, `"answer":true|false`, `explain` обов'язково (особливо для хибних);
- `order`: `"steps":["крок 1","крок 2","крок 3"]` у **правильному** порядку (застосунок перемішає);
- `code`: `"code":"…"`, `"lang":"bash"`, `"mode":"output"` (що виведе) або `"complete"` (допиши рядок), `"answer":"…"`, `"accept":[]`;
- `flip`: `"a":"коротка відповідь"`, `"why":"чому / приклад"` (терміни й визначення).
Пропорції на W (8 карток): 3 mcq, 1 cloze, 1 tf, 1 order або code, 2 flip. Код/таблиці — markdown, формули — `$x^2$`.
**Що питати (2.0.1).** Картка перевіряє **знання або вміння з матеріалу** — поняття, механізм, формулу, крок алгоритму,
команду, правильний запис коду, розрахунок. Тест: «чи допоможе ця відповідь розв'язати задачу на колоквіумі/лабі?».
**НЕ робити карток з організаційної інформації:** коли/де іспит чи колоквіум, дати й терміни здачі, наступне заняття
і його тема, аудиторія, присутність, кількість балів, формула оцінки, ім'я викладача, канал здачі, «що буде за 2 тижні».
Таку інформацію **використай за призначенням**:
| Що прозвучало | Куди |
|---|---|
| термін здачі / дата колоквіуму чи іспиту | `result.json → todos` (для **будь-якого** типу заняття, і W теж) + `memory.md → Terminy i zaliczenie` + розділ «Do oddania»/рядок у конспекті |
| що здати і в якій формі, що має бути у звіті | `checklist` (L/P) або «Do oddania» + `memory.md → Jak chce prowadzący` |
| як викладач хоче **правильно писати/робити** (дужки при and/or, тестбенч без циклів, фільтр на скріні, одиниці, позначення) | **так, картка** — але сформульована як вміння: «Jak poprawnie zapisać…», «Co jest błędem w…», «Popraw kod…», `code`/`tf` з пасткою; `important: true` |
| «це буде на іспиті» про конкретну тему | сама тема → картки з `important: true`; дата іспиту → todos/пам'ять |
| наступне заняття, що повторити | рядок «Następny wykład / Przygotowanie» у конспекті + пам'ять, **без карток** |
Застосунок сам ховає картки, схожі на організаційні (`study.is_org`), тож такі картки — марна робота.
Перед записом `quiz.json` перевір: `python3 ../tools/quizlint.py quiz.json` — підозрілі картки переформулюй або прибери.

**Переробка карток** (студент натиснув «Переробити конспект»): якщо нова картка замінює стару, додай `"prev":"<точний текст старого q>"` —
прогрес студента перенесеться. Не дублюй тексти `q` в одній лекції.
