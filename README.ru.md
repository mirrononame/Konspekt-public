# Конспект

[Українська](README.md) · [English](README.en.md) · **Русский**

Пошаговая инструкция с картинками: [docs/GUIDE.ru.md](docs/GUIDE.ru.md).

Записываешь лекцию, и к вечеру у тебя PDF-конспект на 3–4 страницы. Аудио бесплатно расшифровывается на твоём ПК,
а конспект пишет твой Claude. Отдельный ключ API не нужен, хватит обычной подписки Claude.
Сделано для студентов Politechniki Wrocławskiej: расписание берётся из USOS, материалы — из ePortal.
Интерфейс — на украинском, английском или русском (Настройки → «Язык интерфейса»), конспекты — на польском, украинском или русском.

Что умеет:
- **Лекции.** Запись с телефона или ПК, аудио, видео из Teams, слайды, фото доски. Предмет и дата определяются по расписанию.
- **Конспекты.** «Za 1 minutę», объяснения простыми словами, типичные ошибки, вопросы для самопроверки. Все конспекты предмета можно собрать в один PDF.
- **Лабы и проекты.** Бросаешь условие, жмёшь «Скопировать запрос» и работаешь с Claude в отдельном чате. Журнал помнит, на чём вы остановились.
- **Семестр.** Дедлайны из ePortal, условия зачёта, оценки, календарь в телефоне, уведомления.
- **Обмен.** Готовые конспекты можно передать однокурснику одним файлом.

Всё хранится в папке `data/` на твоём ПК. Никуда ничего не отправляется, кроме того, что ты сам дал читать Claude.

## Что нужно
- Windows 10 или 11.
- Подписка Claude (Pro или Max) и приложение [Claude Desktop](https://claude.ai/download).
- Python 3.10+. Если его нет, `start.bat` попробует установить Python сам.
- Для расшифровки: ~3 ГБ свободного места. С видеокартой NVIDIA расшифровка идёт в несколько раз быстрее, но и без неё работает.

## Установка (5 минут)
1. Скачай код: **Code → Download ZIP** и распакуй, например, в `Documents\Konspekt`.
   Или `git clone`, если пользуешься git.
2. Дважды щёлкни **`start.bat`**. Первый запуск создаст окружение и установит зависимости (нужен интернет).
   Браузер откроется на `http://127.0.0.1:8765`.
3. Запусти **`create-shortcut.bat`**: на рабочем столе появится ярлык «Konspekt» и, если захочешь, автозапуск с Windows.

## Первые шаги в приложении
1. **Язык.** Настройки → «Язык интерфейса» → Українська, English или Русский.
2. **Расписание.** Настройки → «USOS — расписание» → вставь ссылку из USOSweb («Mój plan» → «Udostępnij plan»).
   Предметы и занятия появятся сами. Можно и вручную: Ещё → Расписание.
3. **Расшифровка.** Настройки → «Локальная расшифровка» → «Установить». Модель (~1,6 ГБ) загрузится во время первой расшифровки.
4. **ePortal** (необязательно). Настройки → «ePortal» → «Подключить». Приложение получает только ключ доступа, как мобильное приложение Moodle. Пароль не сохраняется.

## Подключить Claude
Claude читает папку `data/` и пишет туда конспекты. Инструкцию для него (`data/CLAUDE.md`) приложение кладёт туда само.

1. Открой **Claude Desktop → Cowork** и создай проект «Конспект».
2. Папкой проекта выбери `data` из папки приложения. Точный путь — в Настройки → «Подключить Claude» → «Путь к папке».
3. В инструкцию проекта вставь текст с кнопки «Инструкция проекта» там же:
   > Это папка приложения «Конспект». Сначала прочитай CLAUDE.md в этой папке и работай по нему.
   > Не открывай папки backups и trash. Пиши мне по-русски, коротко.
4. Добавь лекцию в приложении, а потом в новом чате проекта напиши **«Обработай новые лекции»**.
   PDF появится в приложении сам через несколько секунд после того, как Claude закончит.

Вместо Cowork можно взять Claude Code: запусти `claude` в папке `data` и напиши ту же фразу.

**Лаба или проект.** На странице лабы (или «Предмет → Проект») нажми «Скопировать запрос» и вставь его в новый чат проекта.
Claude прочитает условие, твой код и журнал предыдущих чатов, а в конце допишет журнал. Следующий чат продолжит с того же места.

## Поделиться конспектами с однокурсником
**Ты:** Настройки → «Обмен конспектами» → отметь предметы → «Скачать пакет». Отправь `.zip` любым способом.
В пакет идёт то, что помогает учиться: PDF-конспекты, инструкции к лабам, условия заданий, память предмета, план тем.
Аудио, твои заметки, оценки и ключи доступа в него не попадают. Расшифровки, слайды и проекты добавляются, только если ты их отметишь.

**Друг:** Настройки → «Обмен конспектами» → перетащи `.zip` → «Импортировать». Сначала приложение покажет, что именно добавит.
Предметы сопоставляются по названию, новые добавляются в расписание. Свои конспекты никогда не перезаписываются:
если у друга уже есть конспект того же занятия, оно пропускается.

## Телефон
- **Дома** — `start-lan.bat`, приложение будет доступно в домашнем Wi-Fi.
- **Откуда угодно** — `tailscale-setup.bat`. Бесплатный Tailscale открывает приложение только для твоих устройств по адресу `https://<пк>.<сеть>.ts.net`.
  На телефоне установи Tailscale, войди тем же аккаунтом и добавь страницу на главный экран.

ПК должен быть включён, а «Конспект» — запущен.

## Данные и безопасность
- `data/` — обычные файлы: конспекты (`lectures/<id>/output/`), память предметов, расписание. Каждый день делается архив в `data/backups/`.
- `secrets/` — ключи ePortal, USOS и уведомлений. Эта папка лежит отдельно от `data/`, поэтому Claude с доступом к `data` их не видит.
- Обе папки в `.gitignore`: если форкнешь репозиторий, они не попадут на GitHub.
- **Обновление:** замени всё, кроме `data/` и `secrets/`, и перезапусти `start.bat`.

## Для разработчиков
- FastAPI + чистый JS без сборки. Сервер — `app/server.py`, протокол для Claude — `app/CLAUDE.md` и `app/protocol/`.
- Переводы интерфейса — `app/static/i18n/en.json`, `ru.json` (ключ — украинский текст, значение — перевод).
- Тесты: `pip install -r requirements-dev.txt`, `playwright install chromium`, `python -m pytest -q tests`.
  Тесты работают на синтетических данных во временной папке.
- Что менялось — `CHANGELOG.md` (на украинском). Заметки для Claude Code, если развиваешь приложение с ним, — `CLAUDE.md`.
