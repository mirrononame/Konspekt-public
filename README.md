# Конспект

Записуєш лекцію, і ввечері маєш PDF-конспект на 3–4 сторінки. Аудіо безкоштовно розшифровується на твоєму ПК,
а конспект пише твій Claude. Окремого ключа API не потрібно, вистачить звичайної підписки Claude.
Зроблено для студентів Politechniki Wrocławskiej: розклад береться з USOS, матеріали з ePortalu. Інтерфейс українською, конспекти польською (мову можна змінити).

Що вміє:
- **Лекції.** Запис з телефона чи ПК, аудіо, відео з Teams, слайди, фото дошки. Предмет і дата визначаються за розкладом.
- **Конспекти.** «Za 1 minutę», пояснення простими словами, типові помилки, питання для самоперевірки. Усі конспекти предмета можна зібрати в один PDF.
- **Лаби й проєкти.** Кидаєш умову, тиснеш «Скопіювати запит» і працюєш з Claude в окремому чаті. Журнал запам'ятовує, на чому ви зупинились.
- **Семестр.** Дедлайни з ePortalu, умови заліку, оцінки, календар у телефоні, сповіщення.
- **Обмін.** Можна передати готові конспекти однокурснику одним файлом.

Усе зберігається в папці `data/` на твоєму ПК. Нікуди нічого не відправляється, крім того, що ти сам дав читати Claude.

## Що потрібно
- Windows 10 або 11.
- Підписка Claude (Pro або Max) і застосунок [Claude Desktop](https://claude.ai/download).
- Python 3.10+. Якщо його немає, `start.bat` спробує встановити Python сам.
- Для розшифровки: ~3 ГБ вільного місця. З відеокартою NVIDIA розшифровка йде в кілька разів швидше, але й без неї працює.

## Встановлення (5 хвилин)
1. Завантаж код: **Code → Download ZIP** і розпакуй, наприклад, у `Documents\Konspekt`.
   Або `git clone`, якщо користуєшся git.
2. Двічі клацни **`start.bat`**. Перший запуск створить середовище й встановить залежності (потрібен інтернет).
   Браузер відкриється на `http://127.0.0.1:8765`.
3. Запусти **`create-shortcut.bat`**: з'явиться ярлик «Konspekt» на робочому столі і, якщо захочеш, автозапуск з Windows.

## Перші кроки в застосунку
1. **Розклад.** Налаштування → «USOS — розклад» → встав посилання з USOSweb («Mój plan» → «Udostępnij plan»).
   Предмети й заняття з'являться самі. Можна й вручну: Ще → Розклад.
2. **Розшифровка.** Налаштування → «Локальна розшифровка» → «Встановити». Модель (~1,6 ГБ) завантажиться під час першої розшифровки.
3. **ePortal** (необов'язково). Налаштування → «ePortal» → «Підключити». Застосунок отримує лише ключ доступу, як мобільна апка Moodle. Пароль не зберігається.

## Підключити Claude
Claude читає папку `data/` і пише туди конспекти. Інструкцію для нього (`data/CLAUDE.md`) застосунок кладе туди сам.

1. Відкрий **Claude Desktop → Cowork** і створи проєкт «Конспект».
2. Як папку проєкту вибери `data` з папки застосунку. Точний шлях є в Налаштування → «Підключити Claude» → «Шлях до папки».
3. В інструкцію проєкту встав текст з кнопки «Інструкція проєкту» там само:
   > Це папка застосунку «Конспект». Спершу прочитай CLAUDE.md у цій папці й працюй за ним.
   > Не відкривай папки backups і trash. Пиши мені українською, коротко.
4. Додай лекцію в застосунку, а потім у новому чаті проєкту напиши **«Оброби нові лекції»**.
   PDF з'явиться в застосунку сам за кілька секунд після того, як Claude закінчить.

Замість Cowork можна взяти Claude Code: запусти `claude` у папці `data` і напиши ту саму фразу.

**Лаба чи проєкт.** На сторінці лаби (або «Предмет → Проєкт») натисни «Скопіювати запит» і встав його в новий чат проєкту.
Claude прочитає умову, твій код і журнал попередніх чатів, а наприкінці допише журнал. Наступний чат продовжить з того самого місця.

## Поділитися конспектами з однокурсником
**Ти:** Налаштування → «Обмін конспектами» → познач предмети → «Завантажити пакет». Надішли `.zip` будь-яким способом.
У пакет іде те, що допомагає вчитися: PDF-конспекти, інструкції до лаб, умови завдань, пам'ять предмета, план тем.
Аудіо, твої нотатки, оцінки й ключі доступу в нього не потрапляють. Розшифровки, слайди й проєкти додаються, лише якщо ти їх відмітиш.

**Друг:** Налаштування → «Обмін конспектами» → перетягни `.zip` → «Імпортувати». Спершу застосунок покаже, що саме додасть.
Предмети зіставляються за назвою, а нові додаються в розклад. Свої конспекти ніколи не перезаписуються:
якщо в друга вже є конспект того самого заняття, його пропущено.

## Телефон
- **Удома** — `start-lan.bat`, застосунок буде доступний у домашній Wi-Fi.
- **Звідусіль** — `tailscale-setup.bat`. Безкоштовний Tailscale відкриває застосунок лише для твоїх пристроїв за адресою `https://<пк>.<мережа>.ts.net`.
  На телефоні встанови Tailscale, увійди тим самим акаунтом і додай сторінку на головний екран.

ПК має бути ввімкнений, а «Конспект» — запущений.

## Дані й безпека
- `data/` — звичайні файли: конспекти (`lectures/<id>/output/`), пам'ять предметів, розклад. Щодня робиться архів у `data/backups/`.
- `secrets/` — ключі ePortalu, USOS і сповіщень. Ця папка лежить окремо від `data/`, тож Claude з доступом до `data` їх не бачить.
- Обидві папки в `.gitignore`: якщо форкнеш репозиторій, вони не потраплять на GitHub.
- **Оновлення:** заміни все, крім `data/` і `secrets/`, і перезапусти `start.bat`.

## Для розробників
- FastAPI + чистий JS без збирання. Сервер — `app/server.py`, протокол для Claude — `app/CLAUDE.md` і `app/protocol/`.
- Тести: `pip install -r requirements-dev.txt`, `playwright install chromium`, `python -m pytest -q tests`.
  Тести працюють на синтетичних даних у тимчасовій папці.
- Що змінювалось — `CHANGELOG.md`. Нотатки для Claude Code, якщо розвиваєш застосунок з ним, — `CLAUDE.md`.
